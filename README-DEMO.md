# EasyMARL Demo Repository

This is a **read-only demonstration** of EasyMARL - a comprehensive Multi-Agent Reinforcement Learning framework.

## 🚀 Quick Start

Click the button below to launch a live demo in GitHub Codespaces:

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/YourUsername/EasyMARL-Demo)

The demo will automatically:
- ✅ Start Flask backend on port 5000
- ✅ Start React frontend on port 3000  
- ✅ Open the demo in your browser
- 🔒 Block all training operations (read-only)

## 🎯 What You Can Do

### ✅ **Explore the Interface**
- Browse available MARL algorithms
- View algorithm documentation and parameters
- Explore different environments
- See configuration options

### ✅ **View Code Structure**
- Examine the React frontend code
- Review Flask API endpoints
- Study algorithm implementations
- Check environment configurations

### ❌ **What's Disabled (Demo Mode)**
- Training operations are blocked
- File modifications are prevented
- Git operations are disabled
- Sensitive operations are restricted

## 📋 Demo Features

- **React Frontend**: Modern web interface for MARL
- **Flask Backend**: REST API serving algorithm data
- **Smart Connectivity**: Automatic backend detection
- **Security**: Rate limiting and input validation
- **Environment Detection**: Codespaces-optimized URLs

## 🔧 Technical Details

- **Frontend**: React 18 with Tailwind CSS
- **Backend**: Flask with CORS and rate limiting  
- **Environment**: Python 3.11 + Node.js 18
- **Deployment**: GitHub Codespaces ready
- **Security**: Production-grade hardening
